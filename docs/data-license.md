## 授权范围

本项目有权授权的原创代码与原创文档采用 [MIT 许可证](../LICENSE)，包括自行编写的数据构建、查询、导出与验证工具。复制或分发这些内容时，应保留许可证及版权声明。

数据文件与第三方内容的授权按下表区分。

| 内容 | 说明 |
|---|---|
| `app-data/`、`app-runtime/` 中的数据包 | 包含来源数据及整理结果，不统一声明为 MIT 授权 |
| `raw/` 中的来源素材与审核资料 | 保留相应来源、原始内容及处理记录；第三方引用不因收录而改用 MIT |
| 古代作品原文 | 与现代译注、赏析、校订文本分别核查其适用的使用条件 |
| 现代译文、注释、赏析、作者资料和头像等 | 保留原权利归属，使用范围以相应授权为准 |
| AI 辅助生成或编辑的内容 | 保留生成、编辑与审核标记；该标记不构成第三方内容的授权证明 |

本项目的代码许可证不为第三方内容授予额外权利。清洗、纠错、去重、格式转换或压缩存储均不改变原内容的授权条件。

## 主要来源

主要来源为 [yxcs/poems-db](https://github.com/yxcs/poems-db)。其 README 表示整理数据可以使用，同时说明数据来自古诗文网。该说明为上游作者的使用声明，本项目保留来源关系，不将其改述为 MIT 许可证，也不据此确认所有第三方内容均可任意再分发。

名句选取与后续内容核对还参考了相应作品页面、古籍页面及公开资料，具体链接保留在作品记录、`source_url`、来源证据和修订记录中。来源链及授权信息目前尚未逐项核实完成。

接入或分发数据包时，应保留对应来源、授权说明及适用的第三方声明，并根据实际使用场景核实再分发、商业使用和其他使用条件。提供来源链接或完成内容审核本身不代替必要授权。
